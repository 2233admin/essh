Getting around — no prefix needed
F1 Help · F2 Full health · F3 Sessions · F4 Main menu
F5 / F6 Previous / next session · Esc Close or back inside essh
Mouse
Click session tabs to switch. Click a row to select; double-click connects or switches. Scroll panels with the wheel. Click panes to focus and drag dividers to resize.
Health
F2 opens the full dashboard. F2 or Esc returns to the terminal. Tab changes the focused panel; arrows scroll it. b shows the optional side strip. Missing readings show —; disconnected samples show their age.
Advanced terminal keys
Local tmux prefix: Ctrl+A. Remote tmux prefix: Ctrl+B. Ctrl+A, release, then lowercase m toggles the side strip. Ctrl+A then v sends the next key through, including reserved F1–F6. In the terminal, Esc and Ctrl+C still reach your remote program.
Splits
Ctrl+B, release, then % splits side by side; " splits top/bottom. Ctrl+B then an arrow changes remote pane.
