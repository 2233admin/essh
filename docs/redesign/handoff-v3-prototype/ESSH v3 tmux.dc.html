WHAT IT IS
tmux does the work. Every essh session is a tmux window on the remote host. Detach, reconnect, quit — tmux already handles all of it. essh adds a host list, a switcher, and a skinned status bar.
Two screens. Host list and session. The switcher is a tmux popup; help is one page. Nothing else.
Netwatch skin. Square borders, one accent (cyan), green for traffic and health, red only for unreachable. rx/tx braille graphs and a per-peer table in the optional side strip.
Health is three bars and a ping. cpu / mem / disk / rtt in the strip; a dot per host in the list and status bar. No thresholds, no verdicts, no fleet views.
REMOVED VS V2
Health dashboard, "needs attention", host cards, busiest-processes list, reachability panel.
Broadcast, activity log, quick-connect panel, command palette, config screen.
File browser and port forwards — use scp / ssh -L inside the session; can return later as tmux popups.
Numbered btop panels, meters with gradient ramps, six function keys. Down to 12 keys total, six of them tmux's own.
