FIXED — DEFECTS IN THE SHOTS
Duplicated consensus figure. role=web printed "2 / 2 2 / 2 full consensus" — now one bar, one ratio, one note.
Forwards lied. Both rules read "Active" with nothing bound. State is now probed: failed rows carry the reason and a retry key.
"r probe" discarded probe state. Split into p/P probe and R reload; reload keeps live results.
Clipped add-forward hint. Format moved out of the border into its own row, both directions shown.
Help wrapped mid-phrase. "F4 / forwards" gone — the keymap is a grid, so nothing breaks across lines.
"1 peers never probed". Counts are pluralised and unprobed hosts are stated as unknown, never as agreement.
CHANGED — DESIGN
One chrome, everywhere. btop panels: rounded frame, numbered title breaking the top edge, local key hints breaking the bottom edge. No screen invents its own box.
Header collapsed to one line. The empty band under the tabs and the stray "Theme:" echo line are gone; status is three counted dots plus the probe countdown.
Numbers get graphics. Gradient cell meters and braille history replace bare percentages — consensus, per-core CPU, memory breakdown, RTT per host.
Net panel reads like netwatch. Mirrored up/down history over a per-flow table: peer, process, rates.
Colour means severity only. Green ok, yellow diverged, orange worst offender, grey unknown. Cyan is chrome and keys, never data.
Verdicts say why. Hash-vs-consensus lines carry the human cause ("nginx 1.22.1 — expected on role=web").
