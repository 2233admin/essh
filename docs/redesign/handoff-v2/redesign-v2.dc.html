WHAT CHANGED FROM V1
Config divergence is gone. The fleet-consensus screen, the DIVERGE column, groups/agreement and facet verdicts are all removed. Nothing asks you to reason about how hosts differ.
Sessions are the landing screen. One table: which host, attached or detached, what's running, how long, and its last line of output — so you can tell what a session is doing before attaching.
Hosts became a health list. Same table, but the columns are session count, cpu, memory, disk and rtt. Offline hosts explain themselves inline and offer retry, instead of leaving blanks.
Health leads with problems. "Needs attention" names the 3 hosts worth looking at in plain sentences, then cards for those hosts, then busiest processes and reachability. No numbers you have to interpret.
Broadcast replaces the fleet tooling. One command to a tag, with per-host exit codes — the multi-host action people actually want.
Fewer keys, same chrome. Ten function keys became six; the keymap fits one screen. btop panels, meters and braille history are unchanged.
